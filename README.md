# M.A.T.E. para un TV Hisense

Pantalla de inicio con M.A.T.E. para un televisor Hisense con VIDAA. Es una pagina web pensada para manejarse con
el control remoto del TV; en una computadora se ve como vista de prueba.

La fuente Outfit se usa bajo la licencia SIL Open Font License (`fuentes/LICENCIA-OFL.txt`).
